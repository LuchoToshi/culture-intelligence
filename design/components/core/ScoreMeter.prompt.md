Typographic five-cell score meter; the only "chart" the index uses — never blend the three scores into one.
```jsx
<ScoreMeter value={4} />            // editorial or adoption
<ScoreMeter value={5} accent />     // saturation: oxblood at >= 4
```
cellWidth: 12 (table row), 14 (compare card), 22 (dossier header).
